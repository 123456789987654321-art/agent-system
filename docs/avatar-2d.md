# 中性科技感数字人

当前页面采用原创 SVG 分层半身虚拟人，使用银灰面部、石墨肩部和少量青蓝细线，与中控页面的蓝灰配色协调。面部使用简洁的眉骨、鼻梁和眼部结构；不使用夸张眼睛、发型、服装或卡通描边。头颈与肩部是一体式造型。渐变光影和小幅视差提供 2.5D 观感，无需额外数字人账号或 SDK。

## 装饰

耳侧采用小型金属嵌件；肩部加入细密织纹，胸前使用家居轮廓徽章。背景板只增加低对比网格、角标与短线路，小屏紧凑模式隐藏背景细节。所有新增饰件均为静态视觉元素，不表示设备或网络连接状态。饰件随各自的人物/背景图层移动，不新增独立动画。

## 行为

- 未保存大模型 API Key：展示静态形象，不能语音播报或执行智能任务；系统按钮仍可手动操作。
- 头部、颈部和肩部共享一个动画组，只作轻微整体起伏，避免接缝错位。
- 保存 API Key 后：启用轻微整体起伏、眼部动作及鼠标视差；智能体继续通过现有模型接口回答和控制设备。保存配置不代表接口已经验证成功。
- 播报使用浏览器 `speechSynthesis`，优先选择中文语音。嘴部动作由真实的音频开始、结束和失败事件驱动，是简化开合动画，不是音素级口型同步。
- 清空 API Key、切换播报或页面进入后台会停止语音。晚到的旧回调不能重启嘴部动画。
- 不支持浏览器语音时保留文字回复。声音和可用音色由设备及浏览器提供，部分环境需要用户先点击页面；语音失败会显示提示。
- 桌面和手机共用矢量形象；高度受限时显示头像近景。遵循系统“减少动态效果”设置。

## 修改与验证

- 图形：`public/index.html` 中的 `assistant-portrait`。
- 颜色和动作：`public/avatar.css`。
- 页面连接与尺寸适配：`public/avatar-2d.js`。
- 语音生命周期：`public/avatar-speech.mjs`。
- 运行 `npm test` 检查 API 门控、语音播放、取消、错误、长文本分段及其他系统功能。

不要把本地插画已显示、动画播放或保存了密钥当作大模型连接成功的证据；模型调用的成功与失败仍以实际请求结果为准。
