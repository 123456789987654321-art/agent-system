# 中性科技感数字人

当前页面采用自制 SVG 分层半身虚拟人，使用银灰面部、深蓝外层与雾蓝曲面内衬的管家制服，配合少量青蓝细线，与中控页面的蓝灰配色协调。头部参考《飞出个未来》中班德的几何机械语言，采用银灰圆筒外壳、短天线、横向眼罩与分格扬声器嘴部，去除真人眉骨、鼻梁、头发与头盔。眼罩和金属渐变使用低饱和配色，保持与蓝色中控界面的协调。头颈与肩部共享一体式动画结构。渐变光影和小幅视差提供 2.5D 观感，无需额外数字人账号或 SDK。

## 装饰

头部通过圆筒曲面反光、暗蓝眼罩、侧面紧固件和底部环形接缝形成层次；短天线属于造型装饰，不显示网络状态。眼部采用浅灰绿光学窗口与矩形瞳孔，嘴部为固定机械格栅，播放语音时内部灯光随播报状态变化。所有头部细节共享同一动画组。胸前内衬沿胸型延伸至衣身底边，以衣身轮廓裁切，去掉悬空下沿，降低亮度与边缘对比，并缩短胸前灯条；肩部使用细密织纹与一对小型金属扣，胸前使用家居轮廓徽章。制服采用低领口、柔和材质分区和少量青蓝饰边；背景板使用玻璃质感展示框，并增加低对比网格、角标、短线路及底座弧线刻度，小屏紧凑模式隐藏背景细节。服装和背景饰件均为静态视觉元素，不表示设备或网络连接状态。饰件随各自的人物/背景图层移动，不新增独立动画。

## 行为

- 未保存大模型 API Key：展示静态形象，不能语音播报或执行智能任务；系统按钮仍可手动操作。
- 头部、颈部和肩部共享一个动画组，只作轻微整体起伏，避免接缝错位。
- 保存 API Key 后：启用轻微整体起伏、眼部动作及鼠标视差；智能体继续通过现有模型接口回答和控制设备。保存配置不代表接口已经验证成功。
- 播报使用浏览器 `speechSynthesis`，优先选择中文语音。嘴部格栅保持固定，内部灯光由真实的音频开始、结束和失败事件驱动；这是播报状态动画，不是音素级口型或实时声学频谱。
- 清空 API Key、切换播报或页面进入后台会停止语音。晚到的旧回调不能重启嘴部动画。
- 不支持浏览器语音时保留文字回复。声音和可用音色由设备及浏览器提供，部分环境需要用户先点击页面；语音失败会显示提示。
- 桌面和手机共用矢量形象；高度受限时显示头像近景。遵循系统“减少动态效果”设置。

## 修改与验证

- 图形：`public/index.html` 中的 `assistant-portrait`。
- 颜色和动作：`public/avatar.css`。
- 页面连接与尺寸适配：`public/avatar-2d.js`。
- 语音生命周期：`public/avatar-speech.mjs`。
- 运行 `npm test` 检查 API 门控、语音播放、取消、错误、长文本分段及其他系统功能。

不要把本地插画已显示、动画播放或保存了密钥当作大模型连接成功的证据；模型调用的成功与失败仍以实际请求结果为准。
