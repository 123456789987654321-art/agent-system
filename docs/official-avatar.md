# 官方数字人接入

页面已改用魔珐星云官方具身驱动 SDK，固定版本为 `@xmov/avatar@2.4.0`。
有言工作台用于视频创作；本系统需要实时响应家居指令，因此使用同厂商的实时驱动产品。
页面不再加载旧 GLB、旧静态人物图或 Three.js 数字人渲染器。

## 配置

1. 在 [魔珐星云](https://www.xingyun3d.com/) 创建**驱动应用**，选择角色、音色、表演风格，并确认应用可用。
2. 获取该应用的 **App ID** 和 **App Secret**。有言工作台的网址、登录密码以及 DeepSeek 等大模型密钥不能替代这组凭据。
3. 运行 `npm ci`、`npm start`。通过 `localhost` 或 HTTPS 打开系统。手机访问电脑的普通 HTTP 局域网地址不满足官方 SDK 的安全上下文要求；手机部署请配置 HTTPS。
4. 在系统设置中先保存大模型 API Key，再在“官方数字人 · 魔珐星云”填入 App ID、App Secret，点击“连接官方数字人”。
5. 等待资源下载、官方会话和在线回调均成功后，页面才显示“形象已连接”。点击“测试形象播报”验证语音和形象路径。它不验证大模型回答质量或家电执行结果。
6. 需要更换外观时，在官方驱动应用中更换角色，再断开并重新连接。使用可能消耗官方账户额度。

App Secret 不写入 localStorage、sessionStorage、文件或日志。前端提交后立即清空密码输入框，服务端仅在内存中短期保存。浏览器 SDK 使用不可持久化的临时访问令牌和同源会话代理；签名由服务端完成。断开时销毁 SDK 并撤销临时令牌。浏览器异常退出时，心跳租约过期后服务端尝试释放房间并清除凭据。服务端进程异常退出时仍需依赖官方服务端的会话超时回收。

## 行为

- 大模型负责原有问答和家居控制；官方 SDK 负责声音、口型、表情和身体动作。
- 没有保存大模型 API Key 时，不创建数字人会话、不播报；清空 Key 会停止当前播报、关闭麦克风和销毁数字人连接。手动按钮继续可用。
- 没有官方凭据、凭据失效或资源加载失败时显示明确的待配置/失败状态，不用旧人物、录播视频或浏览器 TTS 假装接入成功。已配置大模型时仍可显示文字回复。
- 日报和管家回复通过同一个官方 SDK 播报，停止按钮使用真实的官方打断接口。播报完成只由匹配的 `speak_end` 回调确认。
- 设置中的角色测试不会调用大模型。大模型连通性应另行通过一次真实问答验证。

## 实现与验证

- `services/avatar-gateway.js`：临时凭据、同源检查、会话签名、SDK 协议标志、会话归属与释放。
- `public/avatar-controller.mjs`：连接状态机、过期处理、SDK 生命周期、SSML 转义、真实播报完成回调。
- `public/official-avatar.js`：官方 SDK 的延迟加载、手机/PC 布局、设置操作和页面生命周期。
- `npm test` 包含签名、错误脱敏、租约回收、API 清空竞态和播报完成回调测试。

未提供真实官方应用凭据时，自动化验证使用 SDK 测试替身，且单独验证正式 SDK 文件能加载。
这不等同于真实账户角色已加载；正式验收必须完成上面的第 5 步。
